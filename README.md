# Brotato Game QA Sample

A focused Game QA portfolio project covering functional and exploratory testing of selected systems in *Brotato*.

## Project Overview

This project demonstrates a small, structured QA workflow applied to a released PC game.

Testing focused on:

- Core gameplay flow
- Shop interactions
- Pause / Resume behavior
- Selected settings
- Exploratory interaction scenarios

The scope was intentionally limited to keep the testing focused, reproducible, and suitable as a portfolio sample.

## Test Environment

- **Game:** Brotato
- **Version:** 1.1.15.4
- **Platform:** PC / Steam
- **Operating System:** Windows 10
- **Input Method:** Keyboard + Mouse
- **Display Mode:** Windowed
- **Resolution:** Not displayed in game settings
- **Test Dates:** October 2–3, 2026

## Testing Performed

The project included:

- Smoke testing of the core gameplay flow
- Functional testing of shop behavior
- Pause / Resume and gameplay state testing
- Settings testing
- Exploratory testing using rapid inputs, repeated actions, and state transitions

A total of **23 planned checks** were executed.

- **Passed:** 23
- **Failed:** 0
- **Blocked:** 0
- **Defects Identified:** 0

No defects were identified within the defined test scope.

This project represents a focused testing sample rather than comprehensive coverage of the full game.

The absence of identified defects should not be interpreted as confirmation that *Brotato* is defect-free; results only reflect the selected systems and scenarios included in this test scope.
